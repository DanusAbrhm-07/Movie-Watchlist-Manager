readme_content = """# 🎬 Movie Watchlist Manager

A full-stack web application designed to track, filter, and manage a personal movie backlog, utilizing Python, Flask, and SQLite.

## 🌟 Features

* **Add Movies:** Input a movie title and set its initial watch status ("Yes" or "No").
* **View Watchlist:** Display all saved movies in a clean web interface.
* **Search & Filter:** Search titles dynamically and filter movies by watch status (All, Watched, Unwatched).
* **Toggle Status:** Instantly switch a movie's status between Watched and Unwatched with a single click.
* **Delete Entries:** Remove movies directly from the web interface.
* **Data Persistence:** Uses a lightweight SQLite database (`movies.db`) to ensure data safety, prevent duplicate entries, and eliminate file-saving race conditions.

## 🛠️ Technologies Used

* **Programming Language:** Python 3.x
* **Web Framework:** Flask (for backend server routing, templates, and HTTP handling)
* **Frontend:** HTML and CSS
* **Database:** SQLite (relational database engine)
* **Version Control:** Git & GitHub (feature branches, commits, pull requests)
